# One place for every standup

Open **All standups**, search a ticket or describe what you remember, and narrow
by client, project, dates or note type. Filters live in the URL; search text does
not. Select an entry to read progress, next steps, notes and original sources.

In a private instance, choose **New standup**, assign a client and projects, and
write progress, next and notes. Two meetings today create two independent IDs.
An edit requires the revision you read; a competing edit returns a conflict and
leaves your draft available to copy before loading the latest version.

Blockers have their own IDs and histories. Link an existing blocker to another
entry; resolve it once with evidence. Old entries retain that link and its history.

**Import call** offers manual paste when Granola is unconfigured. A configured
server adapter lists recent calls; preview one before selecting context. Summary
and transcript are separate evidence. Suggestions are drafts, not commitments or
decisions. Importing the same source revision into the same context returns the
existing note; a different context receives a separate attributed entry.

The public demo contains fictional read-only history. Private capture requires
an owner token and a separate namespace. No personal data is migrated at launch.
